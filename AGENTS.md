# AGENTS.md — willdo

## What this is
A simple note-taking app that supports creating, editing, and deleting notes with title and content. Notes can be synced to a CouchDB server.

## Stack
- Frontend app (check for framework in source)
- CouchDB (sync backend)

## Build
```bash
npm install
```

## Run
Check `package.json` for available scripts or open the HTML entry point.

## Structure
- Source files in project root or `src/`
- `package.json` — dependencies
